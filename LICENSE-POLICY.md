# Exact-path license policy

There is no repository-wide license grant. The root `LICENSE` file is the MPL-2.0 legal text used by the Builder/Trainer code and build manifest. It applies only to paths classified as MPL-2.0 in `public-path-license-map.json`. Documentation, schema, Sample Characters, brand assets, mixed NSIS source, and third-party materials use the exact path-specific licenses recorded in that map. Trademark rights are not granted.
