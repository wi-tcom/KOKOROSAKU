# KOKOROSAKU v0.1.0-beta.13

English canonical documentation: [README.md](README.md)

KOKOROSAKUは、SAKU Builderの公開sourceと評価用packageです。Builderの出力はCandidateのままで、Canonical Authorityや承認にはなりません。

## インストールして使う

将来の公式GitHub Releaseから `SAKU Builder_0.1.0-beta.13_x64-setup.exe` を取得します。インストーラーにはコード署名（署名者 wi-t.com Inc.）があります。署名があっても、評判が積み上がるまでWindows SmartScreenが警告を表示することがあります。実行前にSHA-256 `0d4262ca7fa7cb942c304f72637ed1db206728db0016b20c50bf97faf92045a7`（2,455,112 bytes）と一致することを確認してください。installerはgit treeとsource ZIPには含まれません。

## このリリースの変更点

- **パックの標準のスキルを、配られたままの形で保存できるようになりました。** ④出力の「パック標準を保存」で、パックと一緒に配られる「別添」の ZIP から、選んでいるキャラクターの標準のスキルを保存します。
  - 「別添の ZIP を選ぶ」で別添を選び、名札が「名札：WI-T.COM署名有効」のときに「標準のスキルを保存する」を押します。
  - このアプリで作り直したスキル（「再生成して保存」）には、これまでどおり WI-T.COM の署名は付きません。
  - いずれの方法で保存したファイルにも、元のCharacter Pack及びキャラクターに適用される利用条件、出所表示及び再配布の制限が引き続き適用されます。
- **書き出しの層（名札）の署名の状態を、4 つの印で出すようにしました。** 名札：WI-T.COM署名有効／名札：WI-T.COM署名無し／名札：WI-T.COM署名未確認／名札：WI-T.COM署名検証不成立 です。キャラクターの印とは別の札です。「名札：WI-T.COM署名検証不成立」は、名札の署名の検証が成り立ちませんでした。変更・破損その他の検証不一致を含みます（署名の鍵の失効・引退を含みます）。
  - 名札の署名が有効であることは、署名対象データが当社の対応する鍵で署名され、署名後に変更されていないことを示します。内容の正確性、安全性、法令適合性、当社による承認又は権限付与を示すものではありません。
- **出どころを確かめてから書き出すようにしました。**
  - β.13 より前に保存し、出どころの記録が無い行のうち、パックのキャラクターと同じ ID の行は、書き出しません。取り込んだパックの記録を読めなかったときは、そのときだけ書き出しを止めます（キャラクターに問題があるという意味ではありません）。
  - AMU Studio から戻ってきたキャラクターは、元のパックを 1 つに決められるときだけ書き出します。決められないときは、元のパック（同じ版）を取り込んでから、もう一度保存・書き出しをしてください。
- **出どころの記録が無いキャラクターを、自分で作ったものとして確かめて書き出せるようになりました。** 読み込むときに参照を直したもの、一覧を作り直したときに Workspace から戻したもの、前の版の SAKU から引き継いだものが対象です。
  - ①の詳細の「自分で作ったキャラクターとして確かめる」を押し、「自分で作ったキャラクターかの確認」で「はい」を押すと、自分で作ったキャラクターとして書き出せます。
  - この確認は利用者の申告を記録するもので、当社が作成者、著作権その他の権利又は利用権限を確認又は認定するものではありません。
  - パックのキャラクターと同じ ID の行には、このボタンは出ません。確かめた後も、書き出すたびに照らします。後でそのパックを取り込むと、書き出しは止まります。
- **②キャラクター編集の保存は、元の行の出どころを保つようにしました。**
  - パックのキャラクターを直したものは、パックを編集したキャラクターのままです。出どころの分からない行は、②で保存しても、自分で作ったキャラクターにはなりません。
  - ①から開いた行が見つからなくなったときなどは保存しません。入力した内容は残ります。
  - ②の「ダウンロード」「コピー」も、④の .json／.yaml と同じ照らしを通り、同じ文で断ります。
- ⑤「AI動作の調整」のボタン名を、「この内容で適用する」から「この内容でキャラクター編集を開く」に改めました。押すと②キャラクター編集に移ります。②で保存するまで、キャラクターは変わりません。
- **右クリックのメニューを、どの画面でもそろえました。** 入力欄の外では、ブラウザのメニュー（戻る・最新の情報に更新・印刷など）を出しません。Trainer・速さの試験・外のレビュー・マニュアル・ヘルプでも同じです。入力欄の中では、編集の項目（切り取り・コピー・貼り付け・すべて選択・元に戻す・やり直し など）だけを出します。
- **ヘルプ、マニュアル、Trainer を、画面の言語で開くようにしました。** 前は毎回日本語で開いていました。マニュアルと Trainer で言語を選んだときは、選んだ言語を使います。
- 「準備と進め方」のヘルプの案内のカードを、押せる物だと分かる見た目にしました。
- **.json・.yaml の書き出しの説明を改めました。** この SAKU Builder の「個別ファイルインポート」で読み戻せます。AI のプロンプトに貼り付ける場合は、「③実行（プロンプト）」で貼り付ける文をコピーしてください（②キャラクター編集の .json・.yaml のタブにも、同じ案内を入れました）。
- 「①キャラクター選択」のボタンの名前を「サンプルを読み込む」にしました。
- **ヘルプとマニュアルに足しました。** マニュアルには、名札の 4 つの印、④の 2 つの保存の道、調整は②で保存するまで変わらないこと、「出どころの記録が無いキャラクターを、自分で作ったものとして確かめる」手順、新しいカード「保存・書き出しが断られた」（画面に出る文と、次の 1 手の表）を足しました。ヘルプの目次のページには、「パックの標準のスキルを保存する」と「名札の 4 つの印」の節を足しました。
- **保存・書き出しの機能の利用について、AI製品・サービス利用特約の適用範囲を追加しました。** 2026年10月24日20時00分（日本時間）以後に SAKU Builder β.13 以降で開始する保存・書き出しの機能の利用に、AI製品・サービス利用特約（第02条第6項・第7項、第07条第9項）を適用します。条項の本文は変わりません。それより前に開始した処理には、遡って適用しません。くわしくは [AI製品・サービス利用特約](https://www.wi-t.com/aiproductterms) をご覧ください。
- インストーラーとアプリ本体には、前の版と同じく、コード署名（署名者 wi-t.com Inc.、Microsoft の時刻局のタイムスタンプ付き）があります。
- β.12 以前に取り込んだパックで「パック標準を保存」を使うには、「①キャラクター選択」からパックをもう一度取り込んでください（標準のスキルを確かめるための情報は、β.13 で取り込んだときに記録されます）。β.12 で取り込んだパックのほかの書き出しは、取り込み直さなくても使えます（β.11 以前に取り込んだパックは、これまでどおり、どの書き出しにも取り込み直しが要ります）。
- SAKU Builder は、オープンソースとして無料で公開しています。
- 公開済みの v0.1.0-beta.12 は、そのまま残しています。

## インストールせず試す

source archiveのrootをローカルHTTPで配信し、`tooling/builder/index.html` を開きます。module画面の `file://` 直開きは非対応です。

## 開発者

repositoryをcloneし、Node 24.19.0で `npm ci`、`npm run desktop:prepare:public`、`npm run tauri:build` の順に実行します。exact toolchainは `docs/releases/0.1.0-beta.13/BUILD_ENVELOPE.json` を参照してください。
