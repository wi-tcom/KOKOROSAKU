# KOKOROSAKU v0.1.0-beta.12

English canonical documentation: [README.md](README.md)

KOKOROSAKUは、SAKU Builderの公開sourceと評価用packageです。Builderの出力はCandidateのままで、Canonical Authorityや承認にはなりません。

## インストールして使う

将来の公式GitHub Releaseから `SAKU Builder_0.1.0-beta.12_x64-setup.exe` を取得します。インストーラーにはコード署名（署名者 wi-t.com Inc.）があります。署名があっても、評判が積み上がるまでWindows SmartScreenが警告を表示することがあります。実行前にSHA-256 `1c328008673b01037f71894f290e4f19ba6a24e8a98b3bb25d5754587ea78d98`（2,363,544 bytes）と一致することを確認してください。installerはgit treeとsource ZIPには含まれません。

## このリリースの変更点

- **Character を「スキル」の形式（Agent Skills）で保存できるようになりました。** ④出力の「スキルとして保存する」で、この形式を読み込める AI の道具向けに、スキルのフォルダーを ZIP で保存します。書き出したものに、WI-T.COM の署名は付きません。スキルを当社以外の環境で使うときは、席 8（人が判断する席）の確認は、当社の仕組みでは強制されません。必要な場面では、人が判断してください。
- **書き出せる形は、Character の出どころで決まります。**
  - 自作の Character：自作の ZIP（.zip）、スキル、.json／.yaml のどれでも書き出せます。
  - パックの Character（編集していないもの）：スキルだけです。パックの使用条件のまま、ご自分の環境で使えます。パックの許諾を受けた方（法人の場合はその法人）の外の人には渡せません。共有サイトなどの公開の場所に置くことも、渡すことに当たります。
  - パックの Character を編集したもの：自作の ZIP とスキルです。元のパックの使用条件が続きます。.json／.yaml には書き出せません。
  - 見本（サンプル）と、出どころの分からないもの：どの形でも書き出しません。見本は読むだけで、編集して保存することもできません。
  - ④では、書き出せない形のボタンは押せず、理由が出ます。書き出す前に、書き出す中身と、連絡先が紛れ込んでいないかの検査の結果を見て、チェックを入れます。
- **画面の作りを改めました。**
  - 準備と進め方と①〜⑤の画面の上に、共通の帯があります。メニューの行（準備と進め方・①キャラクター選択・②キャラクター編集・③実行（プロンプト）・④出力・⑤SAKU診療所・AMUトレーニングセンター）と、選んでいる Character の行です。
  - 保存に要る 30 項目の進み具合を、3 段（目的と役割・判断と人への引き継ぎ・人格の軸）のバーで出します。
  - ②の「新規作成」で、空の Character から始められます。
  - ②の「内面を支える助手（1+7）」と「SAKU定義とAMU定義、MACHI定義の比較」は章になり、畳めます。
- **一覧の印を、AMU Studio と同じ言葉にしました。** 詳細の「出どころ」の行に、印とその説明が出ます。
- **パックは、署名を確かめてから取り込みます。** 確かめに通らないパックは、Workspace に残しません。断るときは短い文だけを出し、細かい理由は「くわしく」に畳んでいます。
- **自作の Character の ZIP（.saku-character.zip）を、SAKU Builder でも読み込めます。** AMU Studio と同じ決まりです。同じ ID・同じ出どころの Character があるときは、置き換えるかを聞きます。
- **読み込み履歴**は、新しい 3 件を出し、残りはスクロールで見られます。行ごとに「取り込み済み」「取り込まなかった」が出ます。
- **保存しないで離れるのを防ぎます。** ②で書きかけのまま別の画面へ移るときや、ウィンドウを閉じるときに、「保存して進む」「保存せずに進む」「編集に戻る」から選べます。何も書いていない新規作成や、見本を開いただけのときは聞きません。この帯のある画面では、入力欄の外でブラウザの右クリックのメニューが出ないようにしました。
- **ファイルを保存する窓**（④の書き出しと、②のダウンロード）は、毎回 Workspace のフォルダーで開きます。種類の欄に「JSON（*.json）」のように拡張子が出ます。
- **画面の一番下に、アプリ本体の署名の状態が出ます。** 起動したときに Windows で確かめ、WI-T.COM の署名なら「署名：WI-T.COM の署名あり（確かめ済み）」と出ます。
- 英語の表示で、状態の行が日本語に戻ってしまう件を直しました。
- 同梱の見本のパックを、saku-pack-sample 1.2.0 にしました。
- **書き出し機能の利用について、AI製品・サービス利用特約を変更しました。** 2026年10月15日 18:00（日本時間）以後に SAKU Builder β.12 で開始した書き出し処理に、変更後の AI製品・サービス利用特約（第02条第6項・第7項、第07条第9項）を適用します。それより前に開始した処理には、遡って適用しません。くわしくは [AI製品・サービス利用特約](https://www.wi-t.com/aiproductterms) をご覧ください。
- インストーラーとアプリ本体には、前の版と同じく、コード署名（署名者 wi-t.com Inc.、Microsoft の時刻局のタイムスタンプ付き）があります。
- 公開のソースでは、npm の確かめの script のうち `export:verify`・`packs:release:verify`・`occupation:verify` の 3 つは動きません。読み込むファイル（ライセンスの記載が無い参照の写し・試験データと、パックを出す社内の道具）を、公開のソースに入れていないためです。アプリの動きには関係ありません。
- 前の版（β.11）から、上書きでインストールできます。Character の一覧、読み込み履歴、Workspace の場所は、そのまま残ります。一覧の行には、β.12 の印が付きます。β.11 で取り込んだパックの Character を書き出すには、「①キャラクター選択」からパックをもう一度取り込んでください（書き出しに要るライセンスの情報は、β.12 で取り込んだときに記録されます）。
- 公開済みの v0.1.0-beta.11 は、そのまま残しています。

## インストールせず試す

source archiveのrootをローカルHTTPで配信し、`tooling/builder/index.html` を開きます。module画面の `file://` 直開きは非対応です。

## 開発者

repositoryをcloneし、Node 24.19.0で `npm ci`、`npm run desktop:prepare:public`、`npm run tauri:build` の順に実行します。exact toolchainは `docs/releases/0.1.0-beta.12/BUILD_ENVELOPE.json` を参照してください。
