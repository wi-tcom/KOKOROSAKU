パックの標準のスキルを保存する

④出力の「パック標準を保存」で、パックと一緒に配られた「別添」の ZIP から、そのキャラクターの標準のスキルを、配られたままの形で保存できます。保存できるのは、名札が「名札：WI-T.COM署名有効」のときだけです。

名札の 4 つの印

  • 名札：WI-T.COM署名有効：名札の署名を、このアプリの信頼の一覧で確かめられました。
  • 名札：WI-T.COM署名無し：この名札には署名がありません。
  • 名札：WI-T.COM署名未確認：この環境では、名札の署名を確かめられませんでした。変えられたという意味ではありません。
  • 名札：WI-T.COM署名検証不成立：名札の署名の検証が成り立ちませんでした。変更・破損その他の検証不一致を含みます。

名札の署名が有効であることは、署名対象データが当社の対応する鍵で署名され、署名後に変更されていないことを示します。内容の正確性、安全性、法令適合性、当社による承認又は権限付与を示すものではありません。くわしくは、マニュアルの「状態を確認する」をご覧ください。

データの場所とUninstall

キャラクター一覧・取り込み履歴・選択中のキャラクターは、選んだ Workspace の .saku-builder フォルダーに保存されます。%LOCALAPPDATA%\com.wi-t.saku-builder にあるのは作業用の写しです。Uninstall でアプリのデータを削除しても、Workspace の characters・imports・.saku-builder は削除されません。同じ Workspace を開けば、一覧は元に戻ります。
