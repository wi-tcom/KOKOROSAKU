The Builder/Trainer code license does not automatically apply to Character Data.

|---|---|---|
| `tools/vnext/sample-pack/sample-characters.json` | **CC0-1.0** | Exact data for `sample-general-compass`, `sample-erabazu-bridge`, and `sample-wit-guide` only |

No Character data beyond the exact three licensed Sample records is included. Production identities, credentials, mandates, endpoints, SLA, and runtime bindings are also excluded.
