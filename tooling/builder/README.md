## Import the three sample Characters individually

The three sample Characters are not bundled in the beta.1 installer. They are
available in the source ZIP or repository under
`samples/oss-launch/unified-v1/`. On Desktop, open **01 Choose a Character**,
select **Individual import**, and choose one one-Character JSON file at a time.
Do not use Package import for these individual JSON files.

This directory is generated by `npm run public:tooling`. It contains no Character Catalog, Occupation Pack, AMU runtime state, MACHI assignment, credential, permission, or Human Apply execution.
