# Security

Do not disclose vulnerabilities, credentials, personal data, customer data, or confidential information in a public Issue.

The intended private route is GitHub Private Vulnerability Reporting for wi-tcom/KOKOROSAKU. Before repository publication, an administrator must enable that feature and verify it from the repository Security interface. If the private reporting action is unavailable, do not post details publicly.

Security reports do not create a support SLA, approval, or Authority.
