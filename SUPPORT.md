# Support

KOKOROSAKU OSS support is documentation-first, self-service, and best effort.

- General questions: GitHub Discussions Q&A for wi-tcom/KOKOROSAKU after the channel is enabled.
- Reproducible bugs: GitHub Issues using the bug template.
- Security: follow SECURITY.md; never disclose sensitive details in a public Issue.

Guaranteed response time: none. Contractual SLA: none. Paid product support is separate from OSS rights and is not defined here.
